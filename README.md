# mdws-org Homebrew tap

Casks for applications published by mdws-org.

```
brew install mdws-org/tap/squint
```

Squint is a macOS image optimizer that compresses to a perceptual target and keeps the colour profile. Source, releases and README: https://github.com/mdws-org/squint. The cask installs the same signed and notarized dmg the release page offers, and the application updates itself with Sparkle afterwards, so the cask is only the first install.
